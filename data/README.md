# Data provenance

- Primary source: UCI Machine Learning Repository, *Seoul Bike Sharing Demand*.
- DOI: https://doi.org/10.24432/C5F62R
- License: Creative Commons Attribution 4.0 (CC BY 4.0).
- Dataset page: https://archive.ics.uci.edu/dataset/560/seoul+bike+sharing+demand
- Stored file: `SeoulBikeData.csv`, copied without modification from
  https://github.com/Itskindastrange/Seoul-Bike-Sharing-Demand-UCI-Dataset
- Original size: 8,760 observations, 14 columns.
- Period: 2017-12-01 to 2018-11-30.
- Filter in analysis code: drop observations with `Functioning Day=No` (295 hours).
- No personal information is contained in this aggregated dataset.

Attribution: Seoul Bike Sharing Demand [Dataset]. (2020).
UCI Machine Learning Repository. https://doi.org/10.24432/C5F62R.
